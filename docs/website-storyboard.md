# Siddhant Vishnu Portfolio Storyboard

The site is about Siddhant, not Mirage. Mirage appears as the current company and one proof node, but the main character is the builder behind it.

## Core Story

Siddhant enters systems that are unfamiliar, learns how they work, forms a sharp opinion, builds the artifact, then publishes the thinking.

The site should answer one question:

Why is this person inevitable?

## Page 1: Hero / Interface Engine

Message:
I build by entering systems.

Visual:
Light-mode off-white canvas, glass browser engine, faint blueprint marks, tactile paper grain.

Copy direction:
- Siddhant Vishnu
- Founder / product engineer / systems thinker
- I learn unfamiliar domains from first principles, find the leverage point, and ship the artifact that makes the system behave differently.

Role:
This replaces the old Mirage-centered hero. The product is proof, not the identity.

## Page 2: Thinking

Message:
The work starts before the code.

Content:

This gives the site heart and personality. It should feel like a founder who thinks in public, not a resume.
